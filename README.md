# 🧠 Brain Tumor Detection using CNN

## 📌 Overview

This project is a Brain Tumor Detection System built using a Convolutional Neural Network (CNN). It classifies MRI brain images into two categories:

- Tumor
- No Tumor

The model was developed using TensorFlow/Keras and OpenCV in Python.

---

## 🚀 Features

- MRI Image Classification
- CNN-based Deep Learning Model
- Automatic Tumor Prediction
- Displays Prediction Score
- Saves Trained Model
- Accuracy & Loss Graph
- Predicts New MRI Images

---

## ▶️ How to Run

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Train Model

```bash
python model.py
```

### Predict

Place an MRI image named

```
test.jpg
```

inside the project folder and run

```bash
python predict.py
```
